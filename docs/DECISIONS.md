# 设计决策

## 已确认

- D-001：Telegram 是唯一 Gateway。
- D-002：第一阶段只接收和保存，不理解内容。
- D-003：支持文字、图片、语音和视频。
- D-004：每条记录只使用一个 Telegram 消息 timestamp。
- D-005：保存成功只回复 `收到 [hashId]`。
- D-006：`helo` 是不写入日志的健康检查命令。
- D-007：第一阶段不调用 Qwen、Embedding 或 Remote LLM。
- D-008：Remote LLM 未来通过用户手动命令调用，不做定时任务。

## 待决定

- D-009：hashId 使用 UUID 前 8 位还是 SHA-256 前 8 位。
- D-010：图片、语音、视频的最大文件大小。
- D-011：媒体是否永久保存及清理策略。
- D-012：`/analyze` 命令格式和结果 schema。
- D-013：Remote LLM provider 和模型。
- D-014：是否需要转录、OCR、视频理解或向量检索。

未确认的设计只能写入“待决定”，不能提前写进代码默认行为。
