# 需求与验收标准

| 编号 | 需求 | 验收方式 |
|---|---|---|
| REQ-001 | 用户可通过 Telegram 发送文字 | 文字消息产生一条记录 |
| REQ-002 | 用户可发送图片、语音和视频 | 文件下载到本地并产生记录 |
| REQ-003 | 图片和视频 caption 不丢失 | caption 写入文本字段 |
| REQ-004 | 每条记录只有一个 timestamp | 使用 Telegram 消息时间并以 UTC 存储 |
| REQ-005 | 保存成功只回复短确认 | 回复格式为 `收到 [hashId]` |
| REQ-006 | `helo` 检查 Gateway 链路 | 不写入日志，返回在线状态 |
| REQ-007 | 媒体下载失败不能假报成功 | 返回错误，不创建完整记录 |
| REQ-008 | Telegram message ID 去重 | 重复更新不会重复保存 |
| REQ-009 | 用户数据隔离 | 用户 A 无法读取或删除用户 B 的记录 |

非功能要求：SQLite 明文保存；媒体路径安全；限制文件大小和类型；Gateway 重启后数据不丢失；第一阶段不访问任何 LLM；运行日志不得包含原文、媒体、Token 或配对码。
